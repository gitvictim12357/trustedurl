# What is this?

trustedurl.org is an anti-phishing URL authenticator tool that works right in the web browser address bar, just by adding the suffix **.trustedurl.org** to the end of any URL, e.g. **wikipedia.org.trustedurl.org**

    Original URL wikipedia.org + .trustedurl.org = wikipedia.org.trustedurl.org

This resolves to **wikipedia.org**, you can also remove the TLD and enter **wikipedia.trustedurl.org** which also resolves likewise to wikipedia.org

    Original URL without TLD wikipedia + .trustedurl.org = wikipedia.trustedurl.org

Which also resolves to **wikipedia.org**

Now say you instead accidentally tried to access a phishing domain **fakewikipedia.org**

    Phishing URL fakewikipedia.org + .trustedurl.org = fakewikipedia.org.trustedurl.org

This DNS resolution fails, blocking the connection to the phishing site by refusing to resolve the domain, because the phishing domain is not in the trusted.org whitelist.

This URL authentication tool works everywhere a URL does, in all web browsers, all applications, all command line programs, all mobile devices, all cloud servers, all embedded systems, all AI agents. No accounts, no sign up, no cost, no logs, no security holes.

Stop phishing attacks today, if you are ever unsure whether is a domain is authentic or fraudulent, just add **.trustedurl.org** to it to verify it with absolute certainty. Every URL in the whitelist is manually and frequently checked by humans for authenticity and absence of malware.
